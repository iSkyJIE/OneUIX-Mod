## 简体中文

**OneUIX Mod** 基于 [SoClear/OneUIX](https://github.com/SoClear/OneUIX)，是一个专为三星设备设计的 LSPosed 模块。它旨在提供高度可定制的系统体验，解除系统限制，并在状态栏、快捷设置以及系统自带应用中加入更多增强功能。

### ✨ 附加功能

在原版 OneUIX 的基础上，OneUIX Mod 额外加入或增强了以下功能：

#### 系统 UI / 状态栏

- 状态栏双行时钟
- 状态栏显示农历
- 状态栏显示农历年
- 状态栏显示生肖
- 状态栏显示时段
- 状态栏日期与时间显示增强
- 其他状态栏显示与布局增强

#### 其他增强

- 持续同步并兼容原作者 OneUIX 的功能更新
- 针对实际使用体验进行功能优化与调整

> OneUIX Mod 是基于 SoClear/OneUIX 的修改版本。原项目功能与版权归原作者所有，OneUIX Mod 的附加修改由本项目维护。

### 📦 安装要求

- 运行 Samsung One UI 5.0+ 的三星设备。
- Android 13+ (API 33+) 。
- 已获取 Root 权限 (Magisk / KernelSU / APatch)。
- 已安装并激活 **LSPosed** 框架。

### 备份

`/data/misc/[UUID]/prefs/io.github.soclear.oneuix/preference.json`

或者

`/data/misc//apexdata/[UUID]/prefs/io.github.soclear.oneuix/preference.json`

### 🤝 参与贡献

欢迎提交 Pull Request 或开 Issue 讨论新功能与 Bug 修复！
由于 One UI 的更新可能会导致 Hook 失效，如果你发现了失效的 Hook 点，非常欢迎提交 PR 修复。

## English

**OneUIX Mod** is based on [SoClear/OneUIX](https://github.com/SoClear/OneUIX), a powerful LSPosed module designed for Samsung devices. It aims to provide a highly customizable system experience, remove system restrictions, and add further enhancements to the Status Bar, Quick Settings, and native apps.

### ✨ Additional Features

On top of the original OneUIX project, OneUIX Mod adds or enhances the following features:

#### System UI / Status Bar

- Double-line status bar clock
- Lunar calendar in the status bar
- Lunar year in the status bar
- Chinese zodiac in the status bar
- Time period display in the status bar
- Enhanced status bar date and time display
- Other status bar display and layout enhancements

#### Other Enhancements

- Continued compatibility with and integration of upstream OneUIX updates
- Feature optimizations and adjustments based on actual usage

> OneUIX Mod is a modified version based on SoClear/OneUIX. The original project's features and copyrights belong to the original author, while the additional modifications in OneUIX Mod are maintained by this project.

### 📦 Installation Requirements

- Samsung devices running Samsung One UI 5.0+.
- Android 13+ (API 33+).
- Root access acquired (Magisk / KernelSU / APatch).
- **LSPosed** framework installed and activated.

### Backup

`/data/misc/[UUID]/prefs/io.github.soclear.oneuix/preference.json`

or

`/data/misc//apexdata/[UUID]/prefs/io.github.soclear.oneuix/preference.json`

### 🤝 Contributing

Feel free to submit Pull Requests or open Issues to discuss new features and bug fixes!
Since One UI updates may cause hooks to fail, if you find any invalid hook points, you are highly encouraged to submit a PR to fix them.
